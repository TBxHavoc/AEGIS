# OpenJarvis Reference Notes

OpenJarvis was reviewed as an architectural reference. Its current documentation describes five primitives—Intelligence, Engine, Agentic Logic, Memory, and Learning—connected by trace-driven feedback, plus registry-driven engines and agents, hardware-aware engine choice, and composable security.

AEGIS independently implements compatible boundaries for local inference, agents, memory, tools, protocols, traces, and scheduling. OpenJarvis source was not copied and no OpenJarvis installer or dependency was run.

Official references: [repository](https://github.com/open-jarvis/OpenJarvis), [architecture overview](https://open-jarvis.github.io/OpenJarvis/architecture/overview/), [engine](https://open-jarvis.github.io/OpenJarvis/architecture/engine/), [learning](https://open-jarvis.github.io/OpenJarvis/architecture/learning/), and [security](https://open-jarvis.github.io/OpenJarvis/architecture/security/).
