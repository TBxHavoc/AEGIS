# Protocol Intelligence

This page is the brief overview of the Phase 4 protocol subsystem. Protocol lifecycle, persistent version snapshots, API operations, task resolution, permission boundaries, and compliance limits are documented in [PROTOCOLS.md](PROTOCOLS.md).

Protocols are structured user guidance. Drafts require explicit approval before activation; only active, relevant versions are resolved for tasks. The resolver checks categories, scope, triggers, priority, conflicts, and declared permission requirements. Application and operating-system security remain authoritative.
